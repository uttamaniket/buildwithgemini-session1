# My agent: travel-concierge
One-liner: A conversational agent that helps travelers plan and personalize trips with a catalog of destinations and itineraries.

Tool coverage:
- Memory: User travel preferences, budget, dietary requirements, and past trip history
- Tools: Destination lookup, weather checks, itinerary planning
- Catalog/UI: Destinations and venue listings rendered as cards/tables
- Image gen: Generating scenic location & attraction preview images
- Sandbox: Budget calculation and currency conversion

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for calculations
